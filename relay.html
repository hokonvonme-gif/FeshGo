Fesh — relais e-mail (Google Apps Script)

Important : le backend n’envoie un e-mail que si RELAY_URL est défini dans les variables d’environnement Render, et (par défaut) seulement si le destinataire est hors ligne dans l’app.

1. Google Apps Script

Va sur script.google.com → Nouveau projet → colle ce code :

function doPost(e) {
  try {
    var raw = (e && e.postData && e.postData.contents) ? e.postData.contents : "{}";
    var data = JSON.parse(raw);
    var to = data.to;
    if (!to) {
      return ContentService
        .createTextOutput(JSON.stringify({ ok: false, error: "to missing" }))
        .setMimeType(ContentService.MimeType.JSON);
    }
    var subject = data.subject || ("Fesh — message de " + (data.from || "un étudiant"));
    var body = (data.from || "Un étudiant") + " t'a écrit sur Fesh :\n\n"
             + (data.message || "") + "\n\n— Ouvre l'app Fesh pour répondre.";
    MailApp.sendEmail({ to: to, subject: subject, body: body, name: "Fesh" });
    return ContentService
      .createTextOutput(JSON.stringify({ ok: true }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ ok: false, error: String(err) }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  // Test simple dans le navigateur
  return ContentService.createTextOutput("Fesh relay OK — " + new Date().toISOString());
}

2. Déploiement (à faire exactement comme ceci)

  1. Déployer → Nouveau déploiement
  2. Type : Application Web
  3. Description : fesh-relay
  4. Exécuter en tant que : Moi (ton compte Gmail)
  5. Qui peut y accéder : Tout le monde (Anyone)
  6. Déployer → autorise les permissions Gmail si demandé
  7. Copie l’URL qui se termine par /exec

Ouvre cette URL dans le navigateur : tu dois voir Fesh relay OK.

3. Variable d’environnement Render

Dashboard Render → ton service Fesh → Environment → ajoute :

RELAY_URL=https://script.google.com/macros/s/XXXX/exec

Puis Save → le service redémarre.

Optionnel pour tester même si l’app est ouverte :

NOTIFY_EVEN_IF_ONLINE=1
NOTIFY_COOLDOWN_MIN=1

4. Test immédiat

Dans le navigateur (après redeploy) :

https://fesh.onrender.com/api/test-relay?to=TON_EMAIL@gmail.com

Puis vérifie Boîte de réception et Spam / Courrier indésirable sous 1–2 minutes.

Vérifie aussi les logs Render : tu dois voir une ligne Relay → … status=200.

Pourquoi tu ne reçois rien d’habitude

  • RELAY_URL pas défini sur Render
  • Destinataire encore connecté dans Fesh (notification e-mail désactivée si en ligne)
  • E-mail dans les spams
  • Ancien déploiement Apps Script (il faut un nouveau déploiement après chaque modification du code)
  • Quota Gmail / autorisations non accordées au script

Quand le test /api/test-relay fonctionne, les vrais messages Fesh enverront aussi des e-mails.
