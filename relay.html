Fesh — relais e-mail

Page de relais (comme YAKA). Héberge ce fichier sur GitHub Pages.

Le backend Fesh envoie un POST JSON vers l’URL de ton Google Apps Script (déployé en Web App, accès « Anyone »).

1. Google Apps Script

Crée un script sur script.google.com avec ce code :

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var to = data.to;
    var subject = data.subject || ("Fesh — message de " + (data.from || "un étudiant"));
    var body = (data.from || "Un étudiant") + " t'a écrit sur Fesh :\n\n"
             + (data.message || "") + "\n\n— Ouvre l'app Fesh pour répondre.";
    if (!to) return ContentService.createTextOutput(JSON.stringify({ok:false,error:"to missing"}))
      .setMimeType(ContentService.MimeType.JSON);
    MailApp.sendEmail({ to: to, subject: subject, body: body });
    return ContentService.createTextOutput(JSON.stringify({ok:true}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ok:false,error:String(err)}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet() {
  return ContentService.createTextOutput("Fesh relay OK");
}

2. Déploiement Google

  1. Déployer → Nouvelle déploiement → Type : Application Web
  2. Exécuter en tant que : Moi
  3. Qui peut y accéder : Tout le monde
  4. Copier l’URL du déploiement (se termine souvent par /exec)

3. Backend Fesh (.env)

RELAY_URL=https://script.google.com/macros/s/XXXX/exec

Quand un message est envoyé dans Fesh, le destinataire reçoit un vrai e-mail dans sa boîte.
